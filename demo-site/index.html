sampla

A tape-machine recorder for quick voice notes. Chrome extension, Manifest V3.

Sampla records the active browser tab — or the microphone — into a floating tape deck, then lets you trim, loop, and export WAV without opening a DAW. Capture uses tabCapture plus an offscreen document, so the page itself never sees the media stream.

Grabbing a few seconds of tab audio still usually means a screen recorder, an editor, and a file conversion. That is too much friction for a voice note or a one-bar loop. Sampla keeps the whole path on a cassette transport: record, wind, crop, store.

The demos on this page run in the browser with a short original loop synthesized on load. They do not call extension APIs.

Tab audio without a picker

Chrome can capture the active tab with chrome.tabCapture.getMediaStreamId, then hand that id to an offscreen document that owns the AudioContext and MediaRecorder. The popup stays a UI: reels, waveform, library. The offscreen document is the tape path.

Record sources: current tab, a region selection, microphone, or mic mixed with the tab. Captured audio is monitored back to the speakers with a short gain ramp so the native-output handoff does not click. Live peaks (20 ms bins) feed the waveform while you record.

The floating deck is the same popup.html, injected as an iframe. Alt+Shift+S toggles it. Toolbar click requests activeTab; nothing is captured until you press REC.

Tape as the transport

Rewind, play, loop, and record are hardware keys, not timeline buttons. Reel rotation, tape-pack radius, and the tension arm track position the same way a cassette does. The window between the reels is a seven-segment timer.

Try the mock below. Play the original 8-second loop, wind the reels, or press REC to record a new live take from an oscillator graph in this page. LOOP repeats the current tape.

Synthetic audio, generated here — not tab capture. Space plays or stops when the deck is focused. R records, L loops.

Trim, loop, light FX

The waveform is the splice block. Drag the yellow crop handles to set in/out points. LOOP plays only that range. SPEED here changes playback rate so you can hear it immediately; in the extension, speed resamples the selection onto the tape (0.05×–20×) so the export matches what you heard.

The product also has reverse, fade in/out, ±3 dB, cut/copy/paste, undo/redo, and beat-snap bar loops (1 / 2 / 4 bars, plus auto-detect). Those stay in the extension. This playground is the trim/loop/speed path you use constantly.

The real deck windows the tape around a centered playhead. This view shows the whole clip so the crop is obvious.

Drag handles to crop. Click the tape to seek. Arrow keys nudge the playhead; Shift+arrows move the out point.

Local library, WAV out

STORE writes the cropped tape into IndexedDB (sampla-library). The library lists local recordings; you can reload, rename, delete, or export. Export is 16-bit PCM WAV, named from the track title. Quiet ends can be auto-trimmed on new recordings.

Nothing leaves the machine unless you opt into Jam. Use Export WAV on the playground above to download the current crop — same container the extension writes.

Optional Jam / Canvas

Account linking and Canvas upload live in integrations/jam-canvas/. Local recording and WAV export continue to work without it. The hosted sign-in page is a separate deploy; this site does not include Firebase keys or Jam credentials.

Load unpacked

Sampla is not a packaged Web Store build in this repository. Load it as an unpacked extension:

  1. Clone or download github.com/jiangjonathan/sampla.
  2. Open chrome://extensions and turn on Developer mode.
  3. Select Load unpacked.
  4. Choose the repository root — the folder that contains manifest.json.
  5. Pin Sampla, open an ordinary http(s) page, then click the toolbar icon or press Alt+Shift+S.

After code changes, reload the extension card and any page where the floating deck was already open. Requires Chrome and Node 20+ for npm run check.

Design tokens

Page chrome follows this case-study layout (white ground, system sans, ~640px prose). Product UI — IBM Plex Mono, black ground, red stroke — is scoped to the embeds. Tune the deck tokens below; they are CSS custom properties on .deck-embed.

Page

--page-bg
Page background. Default #ffffff.
--page-fg
Body text. Default #000000.
--prose-width
Measure for headings and paragraphs. Default 640px.
--demo-width
Max width for interactive embeds. Default 800px.
--prose-size
Body size. Default 1rem.
--prose-leading
Body line-height. Default 1.55.
--section-gap
Space above h2. Default 70px.

Product embeds

--bg
Deck ground. Default #000000.
--line
Stroke, keys, waveform. Default #ff0000.
--dim
Disabled / idle red. Default #7a1010.
--tape
Tape pack fill. Default #ffffff.
--edit
Crop / edit accent. Default #ffd400.
--ui-font
IBM Plex Mono stack.
--stroke
Hairline width. Default 1px.
